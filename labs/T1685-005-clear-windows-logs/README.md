# T1685.005 – Clear Windows Event Logs

Sigma detection rules for **Disable or Modify Tools: Clear Windows Event Logs**
([MITRE ATT&CK T1685.005](https://attack.mitre.org/techniques/T1685/005/)).

| | |
|---|---|
| **Tactic** | Defense Impairment (TA0112) |
| **Technique** | T1685 – Disable or Modify Tools |
| **Sub-technique** | T1685.005 – Clear Windows Event Logs |

Windows event logs record security-relevant activity. Attackers clear them
to remove evidence of an intrusion (e.g. APT28, NotPetya, LockBit).

## Detection strategy

The rules cover the attack at several stages, so that bypassing one
does not bypass them all:

| Stage | Rule | Data source | Level |
|---|---|---|---|
| Clearing command | [`proc_creation_win_wevtutil_clear_log.yml`](proc_creation_win_wevtutil_clear_log.yml) | Sysmon EID 1 / Security 4688 | high |
| Security log cleared | [`win_security_eventlog_cleared.yml`](win_security_eventlog_cleared.yml) | Security EID 1102 | high |
| Other logs cleared | [`win_system_eventlog_cleared.yml`](win_system_eventlog_cleared.yml) | System EID 104 | high |
| Logging service stopped | [`win_security_clear_event_log_service_shutdown.yml`](win_security_clear_event_log_service_shutdown.yml) | Security EID 1100 | low |
| Direct .evtx deletion | [`file_delete_win_evtx_deletion.yml`](file_delete_win_evtx_deletion.yml) | Sysmon EID 23 | high |

## Requirements

- Sysmon installed, with `FileDelete` events enabled
- Process creation logging (Sysmon EID 1, or Security 4688 with command line)

## Known limitations

- **.evtx deletion**: deleting active logs requires stopping the EventLog
  service, which may prevent the deletion event from being recorded locally.
  Most effective with real-time log forwarding.
- **Event ID 1100**: also generated by every normal shutdown; low-fidelity
  signal on its own.
- **PowerShell in scripts**: `Clear-EventLog` called inside a `.ps1` file
  does not appear in the process command line (would need a `ps_script` rule).
